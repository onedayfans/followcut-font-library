# Attribution and distribution notes

Each file in `fonts/` has a corresponding full upstream notice in `licenses/<font-id>.txt`. Consult that notice for authorship, copyright, Reserved Font Names, and the complete license terms.

The manifest records upstream source URLs. Most source URLs are pinned to the commit or release from which the asset was prepared. Assets built as OFL subsets use a neutral `FollowCut` internal font name; original copyright, attribution, and license terms are preserved. LXGW ZhenKai is shipped as the original, unmodified file due to its additional Reserved Font Name permission.

`獅尾福圓` remains in the catalog manifest as unresolved for tracking, without a binary. It is not distributed here.
